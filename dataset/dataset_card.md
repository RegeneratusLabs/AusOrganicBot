# AusOrganicBot Standards QA

## Dataset Description

Synthetic question/answer pairs generated from organic certification
standards documents (paraphrased answers with section citations, plus
negative examples whose expected answer is a refusal). Designed to
fine-tune small RAG reader models to answer only from retrieved context.

- **License:** CC-BY-4.0
- **Size:** grows per generation run; see `dataset/qa_*.jsonl` in the repo
- **Splits:** deterministic 90/10 train/val by question hash

## Structure

| Field | Description |
|---|---|
| `chunk_id` | `country:source/filename#page::index` of the source chunk |
| `country` / `source` / `edition` | provenance of the standards document |
| `type` | `positive` (answerable) or `negative` (expected refusal) |
| `question` | farmer/certifier-style compliance question |
| `answer` | paraphrased, section-citing answer, or the refusal template |
| `context` | **removed in the publish variant** — verbatim source excerpts stay in the repo only |

## Provenance

Generated by `dataset/generate_qa.py` from documents indexed into the
AusOrganicBot vector store. Source standards are:

- Australia: National Standard for Organic and Bio-Dynamic Produce,
  Australian Certified Organic Standard, NASAA Organic & Biodynamic Standard
- United States: USDA National Organic Program Regulations, 7 CFR Part 205
- New Zealand: Organic Products and Production Act 2023 + Regulations 2025
- European Union: Regulation (EU) 2018/848, Implementing Regulation (EU) 2021/1165
- United Kingdom: retained EC Regulations 834/2007 and 889/2008, SI 2009/842

The standards documents themselves remain the copyright of their issuing
bodies and are not reproduced here. Answers are paraphrases, not excerpts.

## Generation Method

1. Chunk-level generation by an LLM (prompt in `dataset/generate_qa.py`):
   two answerable pairs + one non-answerable question per chunk
2. Optional LLM verification pass (`--verify`) drops unsupported answers
3. Deterministic train/val split

## Known Limitations

- Synthetic; expect generator-model biases — human review recommended
- Chunk-level negatives only; no multi-hop reasoning coverage
- Not legal advice; answers may still be wrong — verify against current
  official texts before use
